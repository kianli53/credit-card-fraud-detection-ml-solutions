# credit-card-fraud-detection-ml-solutions
Testing Decision Tree, Random Forest, Gradient Boosting, Logistic Regression, SVM, and XGBoost with SMOTE on credit card fraud detection Kaggle database. Originally done in Google Colab. 

[Paper publication here](https://www.researchgate.net/publication/395220335_A_Comparative_Study_on_Supervised_Machine_Learning_Algorithms_for_Credit_Card_Transaction_Fraud_Detection)
